Rules reference

Rules are game logic as data. Normative definition: SPEC.md §6.

[
  { "on": "start", "do": "state.score = 0" },
  { "each": "player", "when": "held('jump') && self.body.ground", "do": "self.vy = -500; sound('jump')" },
  { "on": "hit", "tags": ["player", "coin"], "do": "despawn(b); state.score += 1" },
  { "do": "state.hud = 'SCORE ' + str(state.score)" }
]

Rule kinds#

Rules run in array order, once per step, where "rules" sits in systems.

RuleRunsBinds
{ do }every step—
{ each: tag, do }once per entity with tagself
{ on: "start", do }first step only—
{ on: "hit", tags?: [a, b], do }per hit event so far this step, matching tag ordera, b, event
{ on: "contact", tags?: [a, b], do }per physics contact, tags in either ordera (has tag a), b, event
{ on: "<type>", do }per event of that type so far this stepevent

Any rule may add when: "<expression>"; do is a string or an array of strings (joined by ;).

Language#

SyntaxExample
statementsa; b; c
local variablelet n = count('coin')
assignment=, +=, -=, *=, /= on locals or fields: self.data.hp -= 1
if / elseif (state.hp <= 0) { goto('over') } else state.hp -= 1
bounded looprepeat (5) spawn('rock', {x: i * 40, y: 20}) (i = 0…n−1, max 10,000)
operators+ - * / %, == != < <= > >= (strict), && || !, c ? a : b
literals1.5, 'text' or "text", true, false, null, [1, 2], {x: 1, tags: ['a']}
accessself.x, state.items[0], event.name; missing fields are undefined

Values follow JavaScript semantics restricted to JSON data plus entities. + concatenates when either side is a string. Forbidden: __proto__, prototype, constructor, unknown names/functions.

despawn(e)remove an entity (or id)

Events, time, flow#

emit(type, payload?)emit an event (visible to later systems this step)
after(seconds, type, payload?)emit an event later (saved with the world)
goto(scene)switch scene at the end of this step
sound(name)play a sound from sounds
burst(e, n)make an entity's emitter spray n particles
talk(dialogueId, npc?, actor?)start a conversation
inDialogue(actor?)a conversation is open
