Cartridge reference

A cartridge is one JSON document: a scene plus behavior. Every field is optional. Machine-readable schema: schema/scene.schema.json; normative spec: SPEC.md §2.

Entities#

{ "id": "hero", "shape": "hero", "x": 60, "y": 200, "tags": ["player"], "body": {}, "data": { "hp": 3 } }
FieldDefault
ide1, e2, …unique
shapename in shapes (or null)
d / textinline path, or text in the vector font (size 16, align center)
fill, stroke, widthstyle for d/text
x, y, rot, scale0, 0, 0, 1rot in radians, 0 faces +x
vx, vy, vr0velocities (units/s, rad/s), integrated by motion
dragvelocity loss per second, 0–1
z, rx, ry, rz, vz, vrx, vry, vrz3D (ry = yaw)
layer0draw order
parallax, fixed, hidden1, false, falsecamera influence; screen-space UI; skip drawing
tags[]what systems and rules select on
data{}your fields; data.ttl = seconds to live (lifetime)
bodyphysics: {static, sensor, collider: "box"|"circle", restitution, friction, mass, gravity}; read ground, wall
emitterparticles: {shape, rate, burst, life, speed, angle, scale, spin, gravity, shrink, max, tags}
interact{prompt, radius, dialogue, do, once}

Sounds#

{ "jump": { "wave": "square", "freq": 330, "slide": 900, "decay": 0.12, "volume": 0.3 } }

wave (square saw sine triangle noise), freq Hz, slide Hz/s, attack/sustain/decay s, volume, vibrato Hz + vibratoRate, duty (square), lowpass Hz, seed (noise).
