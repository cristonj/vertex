Determinism#

Same cartridge + seed + inputs ⇒ same frames, byte for byte. That's what makes replays, rewind, tests and lockstep work. Keep it by: using random()/rand()/hash()/noise() for randomness, keeping all state in the world, and never reading the clock in game logic.

Frames are text#

toSVG() renders the world as a canonical SVG string; digest() hashes it. Agents read frames as text, tests compare digests, and two runtimes (JS, Python) agree on them exactly.

Multiplayer#

The server runs the same Game. Each player is an entity with data.player; rules running for that entity read that player's input. Clients receive nearby entities as deltas and draw locally. So a single-player cartridge with a multiplayer block is already a multiplayer game.

Glossary#

chunk: square region of a streamed world · dormant: a sleeping chunk's saved entities · focus: entities that keep chunks awake (players) · interest: radius a client receives · HUD: state.hud text overlay · policy: a function that presses actions, for bots/tests · conformance: the test suite every runtime must match.
