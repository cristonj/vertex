Games made of text.

Vertex is an extremely opinionated framework for games made of text. Every asset is an SVG path, every scene is JSON, game logic is a tiny sandboxed rules language, and every run is a replay a few KB long. A whole game fits in a link, and humans and AI agents use the same API.

A game is one document

No build step, no assets, no host code. Safe to load from anywhere, and it runs the same in every Vertex implementation.

{
  "title": "Tiny", "width": 320, "height": 240,
  "shapes": { "ship": { "d": "M10 0 L-8 -6 L-4 0 L-8 6 Z",
                      "stroke": "#7df9ff", "width": 2 } },
  "entities": [{ "id": "ship", "shape": "ship",
                 "x": 160, "y": 120, "tags": ["wrap"] }],
  "keys": { "ArrowLeft": "left", "ArrowRight": "right" },
  "systems": ["rules", "motion", "wrap"],
  "rules": [
    { "each": "ship", "when": "held('left')",
      "do": "self.rot -= 4 * dt" },
    { "each": "ship", "when": "held('right')",
      "do": "self.rot += 4 * dt" }
  ]
}
# run headless, read the frame as text
vertex run game.json --steps 600 --svg frame.svg

# record, scrub, compare runs
vertex run game.json --policy bot.js --record run.json
vertex play run.json --at 240 --png frame.png
vertex diff run.json other.json

# the whole game as a URL
vertex link game.json

# a second implementation, same frames
python py/vertex.py conform

# serve it to hundreds of players
vertex serve game.json --root .

# start a project
npx vertex-engine new mygame

What's inside

Zero-dependency JavaScript for browsers and Node, plus a Python runtime that passes the same conformance suite.

Vectors everywhere

Full SVG path support, gradients, clipping, a built-in stroke font, procedural shapes, morphing. Rendered by WebGL2, Canvas2D, SVG or pure-JS PNG.

Built for agents

Run headless, read JSON snapshots or SVG frames, drive named actions, and play over MCP. Agents can author, play-test and balance games.

Time is data

Deterministic fixed-step simulation. Record, rewind, scrub, branch and diff any run. Multiplayer by exchanging inputs only.

2D, 3D, huge worlds

Physics and platforming, vector 3D with shading and fog, endless streamed procedural worlds, branching dialogue and interactions.

A format with a spec

SPEC.md defines every byte of the canonical frame. Two runtimes, 84 conformance digests, all identical.

Multiplayer built in

An authoritative server with interest management, delta snapshots and dead reckoning. Single-player games become multiplayer without code changes.
